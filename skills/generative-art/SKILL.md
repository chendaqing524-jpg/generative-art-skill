# 生成艺术（流场线条画）

不画画，写规则。这个 skill 用现成的流场生成器 `scripts/gen.js` 按 5 条规则出图，再用无头浏览器渲染成 PNG。

规则整理自设计师观默的开源项目「每天一个设计风格」第 021 期（GitHub：guanmo-ai/design-style）。生成器是另写的实现，没有用原项目的代码和图。

## 5 条规则，以及为什么

1. **换种子，换张画。** 规则不动，只换随机起点。一套参数就是一个系列，用户可以在几张里挑。
2. **同种子可复现。** 同一个种子、同一份 gen.js、同样的参数，画出同一张图。所以每张图都要记下 seed 和参数，用户说"就要第 3 张"时才能原样找回。不同浏览器的抗锯齿可能有细微差别，像素级一致只在同一环境里成立，交付时如实说明。
3. **色板加权。** 按权重抽颜色，一个主色占 25% 到 35%，其余递减。平均分色会让画面发花、没有主次。
4. **每步 4px，间隔 5px，碰到就停。** 线条沿方向场一步步走，用占用网格检查四周，离别的线不到 5px 就停。画面透气、线条不打架，靠的就是这一条。
5. **先大后小。** 先放少量粗线定结构，再放中等线，最后用大量细线填缝。顺序反过来，细线会占满画面，粗线就放不进去了。

## 工作流程

1. **问清用途。** 缺什么问什么，一次问完：用在哪（封面、海报、头像、背景、票券），尺寸，浅底还是深底，有没有品牌色。用户没说的就合理假设，用一句话说明后继续。
2. **准备文件。** 在输出目录里放两样：`gen.js`（复制 `scripts/gen.js`）和页面（复制 `assets/template.html`，改顶部的 `CONFIG`）。两个文件要在同一个目录。
3. **先渲一张。** 运行 `python <skill目录>/scripts/render.py page.html out.png --size 1080x1350`，然后自己打开 PNG 看一眼，再拿给用户。
4. **按症状调参。** 对照下面的速查表，一次只改一两个参数，改完重渲。
5. **出系列。** 参数不变，换 3 到 5 个种子让用户挑。用 `--hash seed=101` 传种子，不用改文件。
6. **交付时写清楚。** 每张图的 seed、尺寸、色板和关键参数，以及复现命令。

## 调参速查

| 症状 | 多半是 | 改什么 |
|---|---|---|
| 线太乱、转得太急 | 方向场振幅大 | `fieldAmp` 调小，比如 `[0.25, 0.6]` |
| 线很短、像毛毛虫 | 频率高或间距大 | `fieldFreq` 调低；`gap` 不超过 5 |
| 画面太空 | 细线不够 | 最后一档的 `tries` 加到 5000 以上，`minLen` 调小 |
| 太满、透不过气 | 线太多太粗 | 减少 `tries`，或把 `gap` 调到 6 到 8 |
| 粗线放不进去 | 档位顺序错了 | `classes` 必须从粗到细排 |
| 颜色发花 | 权重太平均 | 主色权重拉到 30% 左右 |

线宽参考（W 为画布 CSS 宽度）：粗线约 W 的 4%，中线约 2%，细线约 0.5% 到 1%。模板默认按这个比例自动算，`step` 和 `gap` 也按宽度缩放：4px 和 5px 对应 1080px 宽的成图，图越小间距越小，否则小图会显得很空。直接调用 gen.js 画缩略图（宽 150px 左右）时，自己把 `gap` 降到 3 左右。

## gen.js 参数

`GenArt.draw(canvas, options)` 画到一个 canvas 上，返回画出的线条数。

| 参数 | 默认 | 作用 |
|---|---|---|
| `seed` | 7 | 随机种子，规则 1 和 2 |
| `pal` | `GenArt.PALETTE` | `[[颜色, 权重], ...]`，规则 3 |
| `step` / `gap` / `cell` | 4 / 5 / 4 | 每步长度、最小间隔、占用网格格子大小，规则 4 |
| `classes` | 必填 | 从粗到细的档位：`{ widths, tries, maxSteps, minLen }`，规则 5 |
| `bg` | `#121212` | 底色 |
| `fieldAmp` / `fieldFreq` / `fieldComponents` | `[0.3,0.75]` / `[0.3,1.2]` / 3 | 方向场的弯曲程度、疏密、复杂度 |
| `stages` | 全部 | 只画前 N 档，用来演示"先大后小" |
| `center` / `stepsLimit` | 0 / 0 | 起点限制在中心半径内、每条线最多走几步，用来做"从一个点长出来" |
| `scale` | 2 | 画布像素倍率，和渲染的 `--scale` 保持一致 |

`GenArt.seedFrom("user_123")` 把任意字符串变成稳定的种子。

## 常用场景

- **封面和海报背景**：要放标题时，单独渲背景，标题用 HTML 叠在上面，或者在 `CONFIG` 里把画布放进卡片的一个区域。
- **头像**：`seedFrom(用户ID)` 当种子，同一个人永远是同一张。做成方形，再圆形裁切。
- **加载动画**：设 `center`（比如 20），`stepsLimit` 逐帧加大（3、10、40……），就是"从一个点长出来"。
- **系列图和票券**：参数相同、种子不同，编号直接用种子。

## 注意

- 流场只是技法，不要照着某位艺术家的具体作品复刻，比如 Tyler Hobbs 的 Fidenza。
- 用户有品牌色就用品牌色，没有时从默认色板出发调整，并保证线条和底色有足够对比。
- 浅底时把默认色板里的米白换成深色，否则主色会消失在底色里。
- 自己写页面、不用模板时，canvas 的尺寸要用固定的像素值，或者读 render.py 传进来的 `w`、`h`，不要用 `100vw` / `100vh` 或 `innerWidth`。无头浏览器在脚本运行时给的视口偏小，截图前才放大，按视口画的图会被拉伸变形。
